# Security reference artifacts

**Status:** Current source of truth
**Audience:** contributors maintaining mesh authorization, service exposure, and docs hygiene

This directory contains checked machine-readable security reference artifacts. They are not temporary run reports.

| Artifact | Purpose | Validation |
| --- | --- | --- |
| [`mesh-security-surface-inventory.json`](mesh-security-surface-inventory.json) | Exhaustive mesh-callable service-method inventory, permission status, callable feature mapping, tooling selector taxonomy, and stable identity notes. | `scripts/generate_mesh_security_surface_inventory.py --check` validates deterministic generation and `tests/unit/gateway/test_mesh_security_surface_inventory.py` validates schema, method counts, protected permission state, feature taxonomy, selector fields, and identity fields. |
| [`mesh-security-surface-inventory.schema.json`](mesh-security-surface-inventory.schema.json) | JSON Schema for the checked inventory. | The same unit test validates the schema with `Draft202012Validator.check_schema()` and validates the inventory against it. |

Do not overwrite these files with the generic backend inventory generator. `scripts/generate_backend_inventory.py` rejects `docs/security/mesh-security-surface-inventory.json` as an output path because this inventory uses a dedicated checked schema and contract workflow.

The canonical inventory is generated by explicit source constants plus AST inspection of `@method_contract` and `mesh=True` sites:

```bash
uv run python scripts/generate_mesh_security_surface_inventory.py
uv run python scripts/generate_mesh_security_surface_inventory.py --check
```

When updating the inventory, update the generator constants and schema together when needed, then run:

```bash
uv run python scripts/generate_mesh_security_surface_inventory.py --check
uv run pytest tests/unit/gateway/test_mesh_security_surface_inventory.py tests/unit/gateway/test_backend_inventory_output_guard.py -q
uv run python scripts/check_docs.py
```
